# WEDE5112
The Green Canopy Initiative (TGCI) website code implements the organisation's digital strategy as documented in its proposal (TGCI, 2026). Written in HTML5, CSS3, and JavaScript, the code follows a mobile-first approach using the viewport meta tag and media queries at 768px and 480px breakpoints, directly fulfilling the proposal's requirement that "the design will be mobile-first, prioritising the user experience on mobile devices over desktop devices" (TGCI, 2026, p. 4). Typography is implemented through Google Fonts, importing Montserrat for headings and Lato for body text as specified (TGCI, 2026, p. 4), while the colour scheme uses four CSS custom properties — deep forest green, leaf green, leaf bright, and charcoal — to represent the "growth and nature" palette outlined in the proposal (TGCI, 2026, p. 4). A sticky navigation header with a prominent Donate call-to-action button addresses the requirement for a "sticky" menu with "clear and consistent call to actions" (TGCI, 2026, p. 4), supporting the goal to increase online donations by 25% (TGCI, 2026, p. 2). The News & Stories page provides a blog layout with story cards, a featured story, category filters, and a subscription feature, implementing the proposal's requirement for "a blog to post stories, press releases and updates from volunteers and project sites to showcase impact" (TGCI, 2026, p. 3). JavaScript event listeners power interactive elements including category filters, read-more links, and donation buttons, fulfilling the technical requirement that the site be "dynamic and interactive" (TGCI, 2026, p. 5). Semantic HTML5 elements and accessibility features follow W3C (2023) guidelines, improving search engine optimisation and screen-reader compatibility (Shneiderman et al., 2016). The responsive CSS Grid layout using auto-fill and minmax() functions automatically reflows content across devices, supporting the proposal's goal for "quick load times of all pages" (TGCI, 2026, p. 4). The footer provides multiple contact channels and social media links, engaging all four target audiences identified in the proposal: community members, corporate partners, schools, and local government bodies (TGCI, 2026, p. 1). Overall, the code systematically translates the TGCI proposal into a functional, accessible, and responsive digital platform that supports the organisation's mission to "help communities develop and sustain green and sustainable cities through education, action and advocacy" (TGCI, 2026, p. 1).
